## 1. Project overview

Signal Portfolio is my personal portfolio website, created for the AWS Student Builder Challenge: Build Your Tech Superpower. Its purpose is to introduce who I am, present my technical skills and projects, and tell the story of my professional journey in a way that is more memorable than a conventional résumé-style page.

The idea behind the portfolio is captured in the phrase **“From gears to cloud.”** My academic background is in Mechanical Engineering, but my professional interests have expanded into networking, cloud technologies, IoT, technical training, and now Agentic AI. The underlying curiosity is consistent: understanding how systems work, identifying where they fail, and finding ways to improve them.

## 2. The creative feature: an interactive signal experience

I wanted the portfolio to do more than display information. I designed its interactions around the idea of exploring a network.

### Scratch-to-reveal cards

The skills section uses scratch-card interactions. Visitors can scratch the cards to reveal certifications and technical skills. This turns the process of browsing a skills list into a small discovery experience. A reveal-all option is also provided.

### Project vending machine

The projects section is presented as a vending machine. Visitors select a project and use a virtual coin interaction to unlock its description and technologies. The metaphor makes exploring my work feel playful while keeping the project information organized.

### Packet-routing game

The site also includes a small network-routing game. Visitors build a route from a laptop to a cloud destination through a network of routers. The game reflects my networking background and gives visitors a simple, interactive way to engage with the subject.

These features are part of the page rather than separate destinations, so the main portfolio sections remain accessible through the navigation.

## 3. Portfolio content

The website includes the three core content areas requested by the challenge:

- **About Me:** My background, professional interests, and experience.
- **Skills and technical strengths:** Certifications, networking, Python, Linux, containerization, Terraform, and technologies I am currently learning.
- **Projects and achievements:** Learning projects, infrastructure work, field engineering experience, and technical training.

The career journey section presents five stages: Mechanical Engineering, Networking, Cloud and IoT, Teaching, and Agentic AI.

## 4. Technology used

The website is implemented with:

- **HTML5** for the structure and content.
- **CSS3** for the visual design, responsive layout, and animations.
- **JavaScript** for the interactive features and client-side behavior.
- **HTML Canvas** for the animated particle background, scratch-card surfaces, and packet-routing game.
- **AWS Amplify Hosting** to publish the portfolio at a public URL.

The project is a static front-end website. It does not use a separate backend or database.
